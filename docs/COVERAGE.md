## Narrative preservation

The build deduplicates original prose paragraphs without dropping their source aliases, line locations or original file hashes. English prose is retained with privacy redaction. Non-English prose is translated to English through the explicitly approved, anonymized Gemini workflow: all numeric values, hashes, addresses, paths and identifiers were masked before external translation, exact placeholder counts/block ids checked, and values restored locally before final privacy/content filtering.

`verification/COVERAGE.json` reports the actual translated/required block counts and the number of unmapped source paragraphs. A finished package requires `translation_complete=true` and zero untranslated/unmapped paragraph occurrences. This provides mechanical traceability of retained narrative, not a proof that a model translation cannot make a semantic mistake. Numeric placeholders preserve exact technical values; reviewed canonical chapters correct known contradictions.

All code/data fences, native listing/hexdump-like lines, raw JSON/log blocks, credential-like material and raw calibration/vector-like material are deliberately withheld. `catalog/OMITTED_SOURCE_SEGMENTS.json` identifies original source/line ranges and reasons without including their contents. `catalog/OMITTED_CONTENT.json` accounts for additional sensitive/code-like narrative blocks. Obtain originals privately if an exact underlying analysis must be audited. The source catalog must never be described as a byte-for-byte public copy of all private records.

## Asset preservation by reference

`catalog/ASSET_REGISTER.json` accounts for every inventoried file through a relative source alias, size, timestamp, classification and hash where computed. Larger/unhashed files are labelled explicitly, not assigned an invented hash. `catalog/SOURCE_CODE_INDEX.json` supplies computed hashes for1064selected source/build files needed for continuation; it does not license or include those files.

Original firmware, SDKs, shared objects, native models, decompiled/disassembled outputs, private calibration, recordings, raw logs and opaque archives are NOT bundled. For each category use ACQUISITION.md and the source/asset aliases. Recipients must obtain their own authorized copies and exact calibration/clock data. If the owner's private source/measurements cannot be transferred, the recipient must reproduce the documented experiment on new inputs and label it a new reproduction.

Sanitized paths may replace a device serial with an alias. `original_relative_path_sha256` disambiguates the original path without publishing its identifier; it is a path hash, NOT an image/content hash. Use the content SHA for binary/version validation. Exact current local instruction files may later carry a short handoff pointer; verification/SOURCE_POINTER_UPDATES.json maps their original analyzed hashes to byte-identical private backups and records the documentation-only update. These new aliases do not add previously missing research or modify implementation/runtime state.
